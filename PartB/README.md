# PART B – IMPLEMENTATION & EXPERIMENTAL INVESTIGATION (25 Marks)

Each task contains Java source in `src/`, test inputs in `input/`, actual/expected evidence in `output/`, a task README and interpretation. Tasks B2–B4 contain the SQL scripts required to create the assignment test database and tables.

| Task | Implementation |
|---|---|
| B1 | File-store add/find/list, damaged-line handling, buffered/unbuffered line counter and measured growth |
| B2 | Unsafe login vs PreparedStatement and malformed bus-pass file tests |
| B3 | Statement, PreparedStatement and batch insertion; ResultSetMetaData; auto-commit vs transaction failure |
| B4 | Legacy-file validation/migration, rejection report and DatabaseMetaData inspection |

Read each task README for compile/run instructions. The root README distinguishes actual executed evidence from MySQL-dependent tests that still need to be run locally.
